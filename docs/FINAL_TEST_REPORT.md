**فایل‌های تست:** ۹۴ در `tests/Feature` · ۵ در `tests/Unit` · ۴۰ در

## Coverage

🔴 **اندازه‌گیری نشده — و این را عمداً به‌جای عددِ ساختگی می‌نویسم.**

⚠️ هیچ موتورِ پوششی روی این ماشین نصب نیست:

```
php -m | grep -iE "xdebug|pcov"   →  هیچ خروجی
```

بدونِ Xdebug یا PCOV، PHPUnit نمی‌تواند پوشش بدهد. پس هر عددی اینجا
می‌نوشتم ساختگی بود.

⚠️ **و نکته‌ای که مهم‌تر از خودِ عدد است:** پوششِ خطی می‌گوید کدام خط
**اجرا** شده، نه کدام رفتار **سنجیده** شده. تستی که تابعی را صدا بزند و
هیچ ادعایی نکند، پوشش را بالا می‌برد و هیچ باگی نمی‌گیرد.

🔴 **و خرابکاری هم جایگزینِ پوشش نیست.** این دو هدفِ متفاوت دارند و
یکی جای دیگری را نمی‌گیرد:

|              | چه می‌سنجد                   | چه چیزی را نمی‌بیند                                   |
| ------------ | ---------------------------- | ----------------------------------------------------- |
| **پوشش**     | کدام خط **اجرا** شد          | ⚠️ نمی‌گوید تستی که آن خط را اجرا کرد، ادعایی هم داشت |
| **خرابکاری** | آیا محافظ **واقعاً می‌گیرد** | 🔴 نمی‌گوید کدام بخشِ کد اصلاً محافظ ندارد            |

⚠️ یعنی وضعیتِ فعلی این است: **پوشش اندازه‌گیری نشده و جایگزینی هم
ندارد.** خرابکاری فقط دربارهٔ محافظ‌هایی حرف می‌زند که وجود دارند؛ دربارهٔ
کدِ بی‌محافظ ساکت است.

آنچه خرابکاری تا امروز نشان داده، روی مرحله‌های R64 تا R72:

**اگر پوششِ عددی خواستید:** `pecl install pcov` و بعد
`php artisan test --coverage`. ⚠️ ولی رویش هدف نگذارید — هدفِ پوشش،
تست‌های بی‌ادعا می‌سازد.

## Critical Failures

**هیچ‌کدام.** هر پنج کارِ CI سبزند:

```
run 33867889933 · completed success
✓ فرانت   ✓ بک‌اند   ✓ امنیت   ✓ قیدهای دیتابیس روی MySQL   ✓ سرتاسری (سه موتور)
```

⚠️ ولی دو شکستِ واقعی در همین مرحلهٔ آخر رخ داد که ثبتشان مهم‌تر از سبزیِ
امروز است:

**① اسکنِ رازِ کامیت‌شده، اولین شکارش خودش بود.** تا وقتی فایل
ردیابی‌نشده بود سبز بود؛ اولین کامیت ردیابی‌اش کرد و اسکن نمونه‌های
آزمایشیِ داخلش را متهم کرد. ⚠️ راهِ آسان افزودن به سیاههٔ استثنا بود — که
رازِ **واقعی** در همان فایل را هم کور می‌کرد. رشته‌ها شکسته شدند و محافظ
بدونِ استثنا ماند.

**② تفاوتِ زیرپیکسلی بینِ سکوها.** دکمه‌ای که در ویندوز ۴۴ پیکسل گزارش
می‌شود، روی رانرِ لینوکسی **۴۳٫۹۹۹۹۹۸** است. 🔴 درسش: تستی که فقط روی یک
سکو اجرا شود، به دقتِ همان سکو گره می‌خورد.

## آنچه این تست‌ها **نمی‌گویند**

⚠️ سه چیز که سبزیِ CI ثابتشان نمی‌کند و بهتر است کسی خیال نکند می‌کند:

**① که سامانه روی سرورِ واقعی بالا می‌آید.** هیچ استقراری انجام نشده.

**② که پول درست جابه‌جا می‌شود.** منطقِ پرداخت با درگاهِ ساختگی سنجیده
شده؛ بانکِ واقعی رفتارهای خودش را دارد.

**③ که کاربرِ واقعی می‌تواند کار کند.** تست‌های سرتاسری مسیرهای اصلی را
می‌روند، ولی هیچ انسانی با این سامانه کار نکرده است.
