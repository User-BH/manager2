# CI ِ محلی

همان دروازه‌های `.github/workflows/ci.yml` روی سیستمِ توسعه، پیش از push (`scripts/ci-local.mjs`). CI ِ گیت‌هاب سرِ جایش
می‌ماند و تأیید است؛ جای کشفِ خطا این‌جاست.

```bash
npm run ci:local
```

| فرمان                                                       | چه اجرا می‌شود                                  | زمانِ تقریبی |
| ----------------------------------------------------------- | ----------------------------------------------- | ------------ |
| `npm run ci:local`                                          | بیلد ← فرانت و امنیت ← بک‌اند و MySQL ← سرتاسری | ۲۲ دقیقه     |
| `npm run ci:local -- --quick`                               | همه جز سرتاسری                                  | ۶ دقیقه      |
| `npm run ci:local -- --e2e-only`                            | بیلد و سرتاسری                                  | ۱۷ دقیقه     |
| `npm run ci:local -- --e2e-only --spec a.spec.ts,b.spec.ts` | فقط همین سفرها                                  | چند دقیقه    |
| `npm run ci:local -- --parallel`                            | سرتاسری هم‌زمان با بقیه (سریع‌تر، بارِ بیشتر)   | ~۱۷ دقیقه    |

هر کار همان فرمان‌های CI را دارد: `format:check`، `typecheck`، `lint`، Vitest با بودجه‌ی باندل؛ Pint، PHPStan و
PHPUnit؛ `composer audit`، سه سطحِ `npm audit` و امضای پکیج‌ها؛ و Playwright روی پایگاه‌داده‌ی SQLite ِ **تازه** در
پوشه‌ی موقتِ سیستم (هرگز `database/database.sqlite`) با همان env ِ CI (`SUBSCRIPTION_GATEWAY=sandbox`،
`PAYMENT_SANDBOX_ENABLED=true`، `AUTH_PASSWORD_TIMEOUT=5`) و `DemoSeeder`، `otp_disabled` و `E2eSeeder`.

گزارشِ هر کار: `storage/logs/ci-local/<زمان>/`. در پایان جدولِ نتیجه و سطرهای شکستِ هر کار چاپ می‌شود؛ کدِ خروج
فقط با سبزِ همه ۰ است.

## تفاوت با CI ِ گیت‌هاب — صریح، نه پنهان

| مورد                        | این‌جا                                                                                                | چه کنیم                                         |
| --------------------------- | ----------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| Firefox                     | اگر بالا بیاید اجرا می‌شود؛ روی ویندوزِ فعلی با خطای side-by-side بالا نمی‌آید و «ردشده» گزارش می‌شود | نصبِ Microsoft Visual C++ Redistributable (x64) |
| قیدهای MySQL                | با Docker ِ روشن، کانتینرِ `mysql:8.4` روی درگاهِ ۳۳۳۰۶ می‌سازد، اجرا و پاک می‌کند؛ بی Docker «ردشده» | روشن‌کردنِ Docker Desktop                       |
| دو آزمونِ فایلِ ساختگیِ PHP | این‌جا اجرا نمی‌شوند: Defender ِ ویندوز فایلِ web-shell ِ آزمون را قرنطینه می‌کند                     | فقط CI                                          |

ترتیب عمدی است: Vitest با همه‌ی هسته‌ها کار می‌کند و هم‌زمان با PHPUnit آزمون‌های زمان‌دارش ناپایدار شدند؛ و درگاهِ
۸۰۰۱ باید آزاد باشد، وگرنه Playwright سرورِ موجود (شاید روی پایگاه‌داده‌ی دیگر) را به کار می‌گرفت — اسکریپت پیش از
شروع می‌سنجد.
